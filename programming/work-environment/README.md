## Boilerplate
- Boilerplate is a design pattern pre-programmed by monks for developing websites in a faster and more well-structured way, following deployment and development standards.
- [Boilerplate Wordpress github](https://github.com/Raccoon-Monks/Boilerplate-Wordpress)
- In the boilerplate there is documentation that teaches step by step how to install and prepare the environment using rancher.
- src/: Folder where the code and styles of the website templates are located.
- templates/: Folder where the website page templates are located
