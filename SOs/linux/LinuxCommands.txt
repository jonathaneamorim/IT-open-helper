1. Instalar um software .run
> sudo chmod 777 [filename.run]
> sudo ./[filename.run]

2. Criar arquivo pelo terminal 
> touch [filename.extension]

3. Executar o xampp
> Ir até a pasta /opt/lampp/ e executar o comando [sudo ./manager-linux-x64.run]

4. Habilitar permissão para qualquer usuário acessar/modificar uma pasta
> sudo chmod 777 [foldername] -R

5. Instalar um pacote ou programa
> sudo dnf install [program_name]

6. Acessar o terminal como root
> sudo su

7. Ver informações do SO
> (Visualizar comandos de sistema) uname --help
> (Visualizar qual o SO) uname
> (Visualizar versão do SO) uname -srm
- (Ver informações completas - exibe dados de identificação do sistema, incluindo o nome da distribuição e a versão de lançamento) cat /etc/os-release

8. Executar arquivos .run
1- Abra o Terminal
2- Utilize o comando chmod +x arquivo.run para torná-lo executável
3- Utilize o comando sudo ./arquivo.run para executá-lo

9. Instalar arquivo .rpm
> Em arquivos na web
	> Ir até o diretório do arquivo
	> Utilizar o comando 'wget [filename.rpm]'
> Em arquivos locais 
	> sudo rpm -i <fileName>
> Encontrar um app rpm instalado
	> rpm -qa | grep package_name
> Desinstalar app no RPM
	> rpm -e {appName}

10. Editar um arquivo pelo terminal (Utilizando o VIM).
> abrir o arquivo para edição - vim [filename]
> Entrar no modo de inserção de informações - ESC -> i
> salvar arquivo e sair - ESC -> wq

11. Apenas ler um arquivo pelo terminal.
> cat [filename]

12. Baixar arquivo da internet WGET
> Para isso é necessário ter o link direto do download;
> Após isso aplicar o comando WGET [link]
> O arquivo será baixado no diretório em que foi executado

13. Pesquisar texto em arquivos
> Utilizar o comando GREP
> Ele possui várias vertentes e formas de usar
> Geralmente uso GREP -r "text" [directory] (quando deseja que seja no mesmo diretorio onde esta o console é só inserir [.])

14. Extraindo arquivos tar.gz
> Utilizar o comando: tar -xzf [file.tar.gz]

15. Extraindo arquivos tar.xz
> Utilizar o comando: tar -xvf [file.tar.xz]

15. Excluir pasta e todos os itens internos
> rm -rf {foldername}

16. Executar arquivos jar
> java jar (fileName.jar)

17. Ocultar e exibir pastas do PC
> Ctrl + H

18. To update your Fedora Linux release from the command-line do:
> sudo dnf upgrade --refresh

19. KVM and Virtualization Fedora linux
> Package qemu-kvm.x86_64
> Enabling nested virtualization
	> sudo modprobe -r kvm_intel
	> sudo modprobe kvm_intel nested=1

20. SSH
> Gerar key: ssh-keygen -t ed25519 -C "your_email@example.com"
> Subir: eval "$(ssh-agent -s)"
> Subir a chave: ssh-add ~/.ssh/id_ed25519
	> Habilitar ssh serve no fedora
		> sudo dnf install openssh-server
		> sudo systemctl enable sshd
		> sudo systemctl start sshd
		> sudo systemctl status sshd
		> sudo ss -lt

21. Rodar aplicação docker
> systemctl start docker
> systemctl enable docker

22. Conceder permissão de usuário para pastas e subpastas
> sudo chown -R $USER:$USER /caminho/para/sua/pasta/do/projeto

23. Criar atalho na area de trabalho
> sudo nano ~/.local/share/applications/filename.desktop
